     ---> Operators in JS : 
      
       --- Operators helps the developer to perform  calculations on the browser  
        
          --> Operator  :  A symbols between the two variable we call it as operator
            
            ex : 
                     a + b ; --- addition


          --> Operand : The variables are treated as operands while performing the calculations 



      
 ----> Operators in  JS there are 5 types :
   

   1. Arithematic Operators :  We can perform + , - , / , % , *
       
       general mathematics 
        

  2. Compound Assignment Operator : combination arithematic and assignment operator 
   
         (+= , -=, /= , %= , *= , **(Ternary operator))


   3. Comparsion operators : Comparing the two variables we use these operators

      ( == , === , <= , >= ,< , > , != )  
        

        --> == : it comapre two condition if the values are same we get  output as true 
         
        --> === :  we call it as exact Comparsion even though the values are same it checks the data type 
               
                 (if the values are same and the data type is also same then only the output is true)

                 a = 10;
                 b="10";
                console.log( a===b ); // false 

   4. Logical operators : We use this operators to check the conditions 
    
       - &&(AND) -  both conditions should be true then only the output is true otherwise  we get false

       - ||(OR) - atleast one condition must be true then only we get true otherwise we get false

       - !(NOT) - if the condition is  true we get output as false and if the cond is false we get output 
                   as true

      
   5. Increment / Decrement operator : 
     
        (++ , --)

        ---> ++(Increment the original value by +1)

        ---> --(Decrement the original by -1)

    ---> Conditional statements :   The block of code is executed when the conditions matches 
       
       we call it as conditional statements  
        

        1 . if conditional statement  : the block of code is executed when the condition is true 
         
            syntax :  
                   
                        var age =18;
                        if(condition){

                              // True Statement  (True block)
                        }

                               }
                               else { 

                                       // default statement
                               }

-----> Looping control statements/ Iterative control statements :

    ---> loop iterate continuously until the condition  is true 
     
     1. for loop : the loop iterates until the condition is true 
        
          Syntax : 
               
                var i=0;
               for(var i=0; i<=10; i++){

                  // statement
               }

               var i=0 is called as intial condition 
               i<=10 is called as stopping condition 
               i++ is Increment


----> Date : 4/11/26 

     2. While loop :  The loop check the conditions first then the loop execute 
      
         Syntax : 
            
                var i =0;
                while(i<=10){

                  // statement 
                   i++;
                }

     3. Do while loop : The loop execute at least once and at the last the 
                          condition is checked 

         Syntax :   
            
              
                    var i =1;
                    do{

                     // statement ;
                      i++;
                    }while(i<=10);
