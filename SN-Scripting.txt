     ----- Server Side : We are writing the logics to execute on the DB (Table)

                 --- to write server side scripts we navigate to scripts background

                 printing statements in SN (gs.print or gs.info)

        --- DML Operations 
          
          -- Insert() --- allowing the developer to create the records in tables

          -- Update() --- Allowing the developer to update single record  , Multiple records 

          -- Delete() --- Allowing the developer to delete multiple records and a single record

          -- Query () --- Allowing the developer to fetch the data from the tables

          -- RollBack()  --- to revert back  

   

----> Insert() : Creating the records inside the tables  

    Syntax :  
          
            var gr = new GlideRecord("TableName"); // selecting the table
            gr.intialize();  // opening a new record 
            gr.fieldname = "" ;   // accessing the fields and filling the details
            gr.insert();            // saving the form

   ------- GlideAggregate : We use this  GlideAPI / Glide object to perform statistics , calculations

    ---> Aggregate function  -- COUNT , MIN , MAX , SUM , AVG 


     Syntax : 
                
                var ga = new GlideAggregate('tablename');
                ga.addAggregate('Function name');
                ga.query();   // server receives the count 
                  
               if(ga.next()){

                  var result = ga.getAggregate('functionName');
                  gs.info(result);
               }

    Async Script include :
