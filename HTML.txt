---> Structure of HTML 

   -- In HTML everthing that we gonna see and those are treated as TAG 
      
      <>--- angular bracket(open angualr bracket)
      </> -- closed angular bracket 


      <!DOCTYPE html> -- it will tell the browser the DOCTYPE is html(on webbrowser every page type is DOCTYPE html)
        <html> -- in between this tags we gonna define i=our web pages details and content(root element)--entry gate 
       
        <head> --- we define the internal details about the page 
           <title>We define the title of the browser tab</title>
        </head>
        
        <body> --body tell the browser what to display
        </body>
        
        </html> -- exit
